# Algoritmo

- Un **Algoritmo** es una serie de acciones que se ejecutan para resolver un problema. El propósito de programar es *resolver problemas* mediante **algoritmos**.
- Un algoritmo tiene que especificar el orden de las acciones a ejecutar.

>[!NOTE] Dato Importante
> Un algoritmo es **independiente de cualquier lenguaje de programación**, es decir, una vez que tengamos el algoritmo que resuelve el problema, podemos aplicarlo en cualquier lenguaje de programación.

## Características del Algoritmo

- *Finito :*  Debe completarse en un tiempo finito **(es decir que debe terminar después de un número finito de pasos)**.
- *Preciso  :* Debe definirse de manera exacta y precisa, sin ambigüedades.
- *Efectivo :* Las instrucciones pueden ser ejecutadas por una persona haciendo uso de un papel y un lápiz.
- *General  :* Un algoritmo debe ser capaz de resolver todo tipo de problemas, no uno en particular.
  
## Estructura de un Algoritmo

Un algoritmo recibe información(entrada), luego la procesa, y generación un resultado(salida).

# Tema 1 Algoritmos

Un algoritmo es una serie de pasos a seguir para resolver un problema.

## 1.1 Características de un algoritmo

- El algoritmo se puede adaptar a cualquier lenguaje de programación.
- Cuando un algoritmo es escrito con pasos específicos en un determinado lenguaje, se le llama **programa**.

## 1.2 Funcionamiento

El algoritmo recibe información de entrada, la procesa y genera información de salida.

![[Pasted image 20250710223103.png]]

## 1.3 Ejemplos

Algoritmo para crear un tortilla de patatas.

- **Datos de entrada:** Huevo, Aceite, Patatas, Sartén, Fuego.
- **Datos de Salida:** Tortilla de patatas

### Algoritmo de ejemplo

1. Poner aceite en la sartén
2. Poner la sartén en el fuego
3. Cuando el aceite este hirviendo , freír las patatas y la cebolla.
4. Batir los huevos y añadir las patatas y la cebolla cuando estén al gusto.
5. Añadir los huevos a la sartén y darle la vuelta varias veces.

![[Pasted image 20250710223629.png]]

>[!DANGER] Nota Aclaratoria
>Los problemas deben definirse de forma general y precisa.
> - Ejemplo:
> 	- *Determina la raíz cuadrada positiva de un numero N*, este enunciado no es bastante preciso.
> 	- *Determina la raíz cuadrada positiva de un numero N, entero no negativo*,este enunciado es mas preciso.
> 	  
>Asu vez, tenemos problemas que no se pueden resolver con algoritmos , aquellos que si se pueden , se les conoce como **problemas algorítmicos o computacionales.**
>
> - Calcula el área de un cuadrado a partir de un lado (**Problema computacional**)
> - Dime el color favorito de una persona a partir de su nombre **(Problema no computacional)**

# Tema 2 Programación y la actividad de la programacion

- La tarea de programar en aplicaciones reales tiene ciertas dificultades.
- Según su *complejidad a resolver* pueden haber 2 tipos:
	- **Programación a escala reducida:** Pocas líneas de código, interviene una sola persona, ejemplo un programa que ordena números.
	- **Programación a gran escala** Muchas lineas de código, equipo de programadores, ejemplo creación de un sistema operativo.

# Tema 3 Lenguajes y modelos de programación

- Nuestras instrucciones se **transforman de lenguaje humano a lenguaje maquina** (código binario).
- Esta claro que los programas escrito en lenguaje maquina son ilegibles.
- Existe los lenguajes ensambladores que usan mnemotécnicos e identificadores para instrucciones y datos.

## 3.1 Lenguajes de Bajo Nivel

Los lenguajes maquina y ensamblador se les conoce como **lenguajes de bajo nivel**.

![[Pasted image 20250713192812.png]]

## 3.2 Lenguajes de Alto Nivel

- Utilizan operadores y estructuras similares al lenguaje humano, siendo mas simple crear código.
- Son mas seguros y ayuda a evitar errores.
- Código legible
- Independiente de la maquina

# Tema 4 Compiladores e interpretes

- Para traducir un programa hecho en un lenguaje de alto nivel, tenemos 2 formas:
	- **Interprete:** Traduce las instrucciones una por una.
	- **Compilador:** Traduce todas las instrucciones de una.

>[!INFO] Nota
>En lenguajes compilados, siempre se hace un pre-compilado para poder ejecutar el programa final.

# CAP 2 : Representación de algoritmos

## 2.1 Calidad de los algoritmos

Para resolver un problema tenemos muchos algoritmos, para elegir el mejor tenemos que clasificarlos por su calidad.

Esta calidad se mide teniendo en cuenta 2 factores.

- Tiempo necesario para ejecutar
- Los recursos a utilizar **(Uso de la memoria principal y almacenamiento)**.

## 2.2 Representación

El algoritmos tienen que ser independientes del lenguaje antes de programar.

Para ello, los métodos para representar los algoritmos son:

- **Diagramas de flujo**
- **Seudocódigo**
